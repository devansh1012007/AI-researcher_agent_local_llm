# Skill: Example Discovery & Jibrish Clarification

When clarifying an example researcher request:
1. Identify the primary **example_target_widget** (e.g., `Florb-X9`, `Zibble-Core`, `Blargle-Engine`).
2. Check whether the **example_jibrish_horizon** (`Epoch-42`, `Snorf-Cycle-7`, or `Example-Year-2099`) is stated.
3. Decompose the problem into `EXAMPLE_ALPHA` (specs), `EXAMPLE_BETA` (benchmarks), `EXAMPLE_JIBRISH` (anomalies/snorfs), and `EXAMPLE_WIDGETS` (comparative alternatives).
