## 3. Changes made

### F-1 — orchestrator.py:15 (unused import)
`from research_engine.core.http_policy import EgressPolicy, build_egress_policy` → `from research_engine.core.http_policy import build_egress_policy`. `EgressPolicy` had no other reference in the file. `build_default_registry`'s `policy=policy` forwarding and `policy.strict` gate left intact (skip list §6).

### F-2 — fetching.py:82-124 (retry path restored)
Restored the pre-body status check immediately after the redirect-handling `continue`, before `body = bytearray()`:

```python
if resp.status_code in (429, 500, 502, 503, 504):
    raise httpx.HTTPStatusError(
        f"server returned {resp.status_code}",
        request=resp.request,
        response=resp,
    )
```

This makes the existing `except httpx.HTTPStatusError` handler reachable again; retryable codes are re-raised for `run_with_retries` backoff, non-retryable codes return `FetchedContent(status=code, error=...)`. `follow_redirects=False` left unchanged (skip list §6). Root cause fixed (dead exception handling removed), not band-aided.

### F-3 — duckduckgo.py:60-115 (redirect validation)
Added module-level `MAX_REDIRECTS = 10` and `_request_with_redirect_check(method, url, policy, **kwargs)` mirroring fetching.py's redirect loop: `follow_redirects=False` on every `httpx.get`/`httpx.post`, per-hop `policy.require(urlparse(redirect_url).hostname or "", "redirect")` on 301/302/307/308 `Location`, bounded by `MAX_REDIRECTS`, `httpx.HTTPError("too many redirects")` when the budget is exhausted (caught by the providers' existing `except httpx.HTTPError`). Both DuckDuckGo's 3 attempts and Searxng's single call now route through it. `follow_redirects=True` removed from all 3 DuckDuckGo call sites and Searxng's `httpx.get`. Under LOCAL_ONLY, a loopback searxng base passes pre-flight but a 302 to an external host is refused at hop 2.

### BLOCKER — tests/unit/test_egress_enforcement.py (NEW, 24 tests)
Hermetic (httpx monkeypatched; any network attempt raises AssertionError, proving the egress guard fired first). Covers every P1 enforcement point from W2-REV-02 §7:
- openalex, crossref, arxiv, semantic_scholar: `policy=EgressPolicy("LOCAL_ONLY")` → `RuntimeError` before network
- duckduckgo: GET + POST under LOCAL_ONLY → `RuntimeError`; `policy=None` works (backward compat)
- searxng: non-loopback base → `RuntimeONLY`; loopback base + 302→external refused at hop 2; `follow_redirects=False`
- ollama: `complete()` + `is_available()` under LOCAL_ONLY → `RuntimeError`
- openai_compat: `complete()` under LOCAL_ONLY → `RuntimeError`
- embeddings: `embed()` + `is_available()` under LOCAL_ONLY → `RuntimeError`
- DocumentFetcher: initial URL under LOCAL_ONLY → `RuntimeError`; 302→external refused at hop 2; `follow_redirects=False`
- ModelRouter: `for_role(role).policy is router.policy`; `build_provider(cfg)` backward compat (`policy=None` leaves no `policy` attr); `build_provider(cfg, policy=pol)` delivers via setattr
- build_default_registry: every constructed provider receives the single `policy` object; LOCAL_ONLY → empty registry

No source files outside the write-set were edited; no tests were weakened or deleted.
