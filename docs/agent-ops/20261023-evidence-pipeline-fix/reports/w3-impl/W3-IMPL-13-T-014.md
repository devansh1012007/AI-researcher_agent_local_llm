## 3. Root cause

`_SANDBOX_GUARD._guard` reads `_ALLOWED_WRITE_ROOT` as a module global at audit-hook invocation time (runner.py:62). Experiment code executed in the same child namespace can rebind `globals()["_ALLOWED_WRITE_ROOT"]`, changing the effective write root mid-run. A write to `/tmp/escape_test.txt` then succeeds because `_guard` computes `root = abspath("/tmp")` and permits it.

W3-IMPL-12's fix binds the root at definition time via a default argument (e.g. `def _guard(event, args, _root=abspath(_ALLOWED_WRITE_ROOT)): ...`), making rebinding the global ineffective. My test targets exactly this: it must FAIL against the unfixed guard (rebinding works → write succeeds → status COMPLETED, file exists) and PASS against the fixed guard (PermissionError → status FAILED, file absent).
