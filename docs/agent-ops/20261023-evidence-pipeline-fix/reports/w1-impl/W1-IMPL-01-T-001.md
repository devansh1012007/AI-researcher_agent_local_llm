## 3. Changes made

The fix is a one-symbol call-site change: `rejected_ratio` → `duplicate_ratio`. No other behavior of `score_project` changes; `rejected_evidence_ratio` (line 73-74) continues to report rejection independently.

- Adding the test to a new file: rejected. `tests/evaluation/test_eval_framework.py` already tests `score_project` via `run_offline`/`AppConfig` and is the natural home; it is in my WRITE-SET. A new file would be speculative slop.
