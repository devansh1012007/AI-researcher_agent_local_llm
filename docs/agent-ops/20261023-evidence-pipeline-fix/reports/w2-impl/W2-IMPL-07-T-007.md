## 3. Root cause

Both providers called `httpx.get` directly with no egress check at request time. Under `EgressPolicy("LOCAL_ONLY")` a constructed provider could still issue outbound network calls to `export.arxiv.org` / `api.semanticscholar.org`, violating the fail-closed egress guarantee. Root cause: request-time enforcement was missing entirely (only construction-time gating existed, owned by other wave-2 agents). Minimal structural fix: gate each `httpx.get` with `self.policy.require(host, ...)` when `self.policy is not None`.
