## 3. Root cause

Each academic provider makes a single outbound `httpx.get` directly, with no egress policy consultation at request time. Under LOCAL_ONLY, `build_default_registry()` already returns an empty registry (construction-time gating by W2-IMPL-12 / existing http_policy), but an `OpenAlexProvider`/`CrossrefProvider` constructed OUTSIDE the registry would still let `search()` reach the network. The fix: guard each `httpx.get` with `self.policy.require(host, ...)`, skipping when `self.policy is None` (backward compat). Host extracted from the request URL via `urlparse(url).hostname` (per brief §6 gotcha — more robust than hardcoding `BASE`).

## 4. Changes made

### 4.1 src/research_engine/providers/academic/openalex.py

- Added import: `from research_engine.core.http_policy import EgressPolicy` and `from urllib.parse import urlparse`.
- `__init__` signature: `def __init__(self, timeout: float = 20.0, policy: EgressPolicy | None = None):`; stores `self.policy = policy`.
- In `search()`, before `httpx.get`: `url = f"{self.BASE}/works"; if self.policy is not None: self.policy.require(urlparse(url).hostname, "openalex search")`; then `httpx.get(url, ...)`.

### 4.2 src/research_engine/providers/academic/crossref.py

- Same pattern: import `EgressPolicy`, `urlparse`; `__init__(self, timeout: float = 20.0, policy: EgressPolicy | None = None)`; `self.policy = policy`.
- In `search()`, before `httpx.get`: `url = f"{self.BASE}/works"; if self.policy is not None: self.policy.require(urlparse(url).hostname, "crossref search")`; then `httpx.get(url, ...)`.

Decision: raise `RuntimeError` (via `EgressPolicy.require`) BEFORE any network call, so under LOCAL_ONLY a non-loopback host fails fast with no `httpx.get` issued. When `policy is None` the check is skipped entirely — existing callers (orchestrator, failure-semantics tests) unchanged.

## 7. Alternatives considered and rejected

- Hardcode host from `BASE` instead of `urlparse(url).hostname`: rejected — brief §6 gotcha explicitly recommends `urlparse` for robustness; if `BASE` ever changes the hardcoded host would go stale.
- Gate only at construction (rely on `build_default_registry` empty registry): rejected — that is C09 part A (already done / W2-IMPL-12); part B requires per-request enforcement for providers constructed outside the registry.
- Always require (no `None` skip): rejected — breaks `OpenAlexProvider(timeout=timeout)` existing callers and violates the `policy: EgressPolicy | None = None` contract convention.
