`build_default_registry()` constructs an `EgressPolicy` (used only for the LOCAL_ONLY construction-time gate) but never forwards it to the providers it builds. Under HYBRID/ONLINE, providers are constructed without `policy`, so they cannot enforce egress at request time. The egress policy exists but is dead at this call site — zero request-time enforcement (C09 gap per mission 00-mission.md §1: "module + construction gating exist; zero request-time enforcement").
