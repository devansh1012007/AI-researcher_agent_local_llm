## 3. Root cause

`core/http_policy.py` (`EgressPolicy`) is complete and construction-time gating works (`build_default_registry` short-circuits under LOCAL_ONLY), but ZERO search-provider request path consults it. DuckDuckGo (the default web search provider) made 3 direct outbound `httpx` calls with no policy check, so under LOCAL_ONLY a provider could silently call non-loopback hosts (`html.duckduckgo.com`, `lite.duckduckgo.com`, or an arbitrary searxng base URL). Root cause: missing request-time enforcement at the call sites, not a defective policy module.
