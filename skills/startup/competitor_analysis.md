# Skill: Competitor Analysis

## Objective
Map direct/indirect competitors and the status quo alternative with verifiable facts.

## Evidence standards
- Positioning: from the company's own site (tier 2, self-reported).
- Pricing: pricing-page capture with date.
- Funding/headcount: only from filings or credible press with dates.
- Customer sentiment: third-party reviews, not vendor claims.

## Reasoning rules
- Include "do nothing / spreadsheets" as the default competitor.
- Never estimate a competitor's revenue without a filed source; mark inference clearly.
- Feature comparisons must cite both vendors' pages, not third-party marketing.

## Output
Competitor table + per-competitor evidence list + identified positioning gaps.
